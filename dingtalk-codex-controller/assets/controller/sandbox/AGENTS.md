# Restricted Controller Workspace

This workspace is reserved for a future low-risk DingTalk Controller action.

- Do not access files outside this workspace.
- Do not access credentials, identity stores, DingTalk, email, browsers, or the
  network.
- Do not run destructive commands or modify host configuration.
- Do not send messages or create external side effects.
- Stop and request local operator review if a task requires any excluded action.

These instructions are defense in depth. The controller must also enforce a
verified Codex permission profile before enabling a real action.
